# One-Line Pitches — A Day of One-Line Pitches

`main.py` writes one sentence (at most 240 characters) to `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt`): a pitch that would convince a friend who has
never coded to let an AI agent build their first app idea on make.fun.

Run it with:

```sh
python3 main.py
```
